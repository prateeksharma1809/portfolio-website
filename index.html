More about me

As of 2025, I am an application-focused ML and AI engineer who ships end-to-end systems. I work across data, modeling, and production, then make the results usable for real users. I blend model depth with strong software engineering so teams move from demo to production quickly.

What I do

  • End-to-end ML systems: data pipelines, training, evaluation, APIs, monitoring, and iteration.
  • Generative and speech: LLM apps, prompting, Whisper transcription, TTS and model deployment.
  • Computer vision: UNet segmentation, YOLO detection, OpenCV for real-time use cases.
  • RAG and vector search: GPT-based retrieval, Qdrant, secure role-based access to knowledge.
  • Production engineering: FastAPI services, React/React Native frontends, Docker, AWS.
  • Data foundations: SQL, PostgreSQL, MongoDB, Oracle, clean schema design for analytics.

So what that translates into

  • Faster paths from prototype to production with clear observability and rollback plans.
  • Simple, reliable services that other teams can integrate without friction.
  • Measurable impact on latency, accuracy, and user adoption.

Recent highlights

  • Sentari AI: led full-stack build of a privacy-first journaling platform with LLM features, Whisper, embeddings search, FastAPI + Postgres + Supabase, and a React Native iOS app.
  • Role-aware RAG chatbot: FastAPI + GPT + Qdrant with RBAC to keep Finance, HR, Engineering, and Exec documents isolated while enabling natural-language search.
  • Vision tooling: UNet + Dlib for clean face cutouts and background replacement for ID and catalog photos; YOLOv5 for real-time face detection with sub-second latency.
  • Automation: daily blog generator API using GPT, APScheduler, Docker, and Markdown outputs for hands-off content workflows.
